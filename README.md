# No_code_Automation_Basic

## 과제 목표
코딩 없이 Trigger와 Action을 시각적으로 연결해 반복 업무를 자동화한다. 
프로젝트 1에서는 동일하게 설계한 워크플로우를 서로 다른 2개 이상의 자동화 도구로 구현한 뒤 비교/분석 
프로젝트 2에서는 선정한 자동화 도구를 활용하여 자유 주제로 나만의 자동화 파이프라인을 설계·구현한다. 
또한 아래 2가지 프로젝트 산출물을 완성한다.

<br>

### 1. 프로젝트 1 자동화 도구 비교 구현
- 동일한 자동화 워크플로우를 설계하고 2개 이상의 도구로 구현한다. 
- 비교 분석 보고서에 각 도구별 워크플로우 구성 화면 및 실행 결과 화면을 캡처하여 기록한다. 

→ 📁 비교 분석 보고서 :  [자동화 도구 비교분석 보고서](https://exuberant-cuckoo-0b8.notion.site/3c1631db7fe080d7ace0eb0d252683b0)

💻 시나리오 by make🟠 : https://us2.make.com/public/shared-scenario/rf1g5b4KJHe/make-test-project1

💻 시나리오 by Zapier🟢 : https://zapier.com/templates/details/zapiertestproject1-aaa940

<br>

### 2. 프로젝트 2 자유 주제 자동화 설계 및 구현
- 자동화할 반복 업무 1개를 정의한다(프로젝트1보다 고도화된 형태). 
- 자동화 도구 1개를 선정하고 선정한 이유를 작성한다. 
- 설명 또는 다이어그램을 포함하는 워크플로우 설계문서를 작성한다. 
- 설계 문서에는 구현 화면과 실행 결과 화면을 캡처하여 기록한다. 

→ 📁 설계문서 : [자동화 워크플로우 설계문서](https://exuberant-cuckoo-0b8.notion.site/3c7631db7fe080ad8a66c44024b09033)
